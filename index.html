Configurar Firebase

Para sincronizar os dados entre você e a Andreza em tempo real, cole abaixo o objeto de configuração do seu projeto Firebase.

Como obter:
1. Acesse console.firebase.google.com
2. Clique em Adicionar projeto
3. Dê um nome (ex: gastos-semanais) e finalize
4. Clique em </> Web para registrar o app
5. Copie o objeto firebaseConfig
6. Em Build → Realtime Database, crie o banco e deixe as regras como true por enquanto
